Setting Up Bootstrap 5 with Sass

mkdir my-bootstrap-project
cd my-bootstrap-project
npm init -y

npm install bootstrap
npm install --save-dev sass

my-bootstrap-project/
├── scss/
│   ├── _variables.scss   ← custom variables override
│   └── main.scss         ← imports Bootstrap
├── css/
│   └── main.css          ← compiled output
├── index.html
└── package.json

In scss/main.scss:

// Import custom variable overrides BEFORE Bootstrap
@import "variables";
// Import all of Bootstrap (or individual parts)
@import "../node_modules/bootstrap/scss/bootstrap";

In package.json scripts section:

"scripts": {
  "sass": "sass scss/main.scss css/main.css --watch"
}

Then run: npm run sass
