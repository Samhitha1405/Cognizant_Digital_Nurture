Sass Customization: _variables.scss

This page simulates the result of customizing Bootstrap's primary color and border-radius via Sass.

In scss/_variables.scss:
// Override Bootstrap primary color
$primary: #e44d26;
// Override border-radius values
$border-radius: 1rem;
$border-radius-sm: 0.5rem;
$border-radius-lg: 1.5rem;
$border-radius-pill: 50rem;
// Override font family
$font-family-base: 'Georgia', serif;
// Override container max-widths
$container-max-widths: (
  sm: 540px,
  md: 720px,
  lg: 960px,
  xl: 1140px,
  xxl: 1200px
);
In scss/main.scss:
// 1. Override default variables FIRST
@import "variables";
// 2. Then import Bootstrap (uses your overrides)
@import "../node_modules/bootstrap/scss/bootstrap";
