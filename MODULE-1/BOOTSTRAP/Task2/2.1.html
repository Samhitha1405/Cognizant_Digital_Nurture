Bootstrap 5 Directory Structure

css

Contains compiled Bootstrap stylesheets.

  • bootstrap.css – Full unminified CSS
  • bootstrap.min.css – Minified CSS for production
  • bootstrap-grid.css – Grid system only
  • bootstrap-utilities.css – Utility classes only
  • bootstrap-reboot.css – CSS reset/normalize only
js

Contains Bootstrap JavaScript plugins.

  • bootstrap.js – Full JS with all plugins
  • bootstrap.min.js – Minified JS for production
  • bootstrap.bundle.js – JS bundled with Popper.js
  • bootstrap.bundle.min.js – Minified bundle (recommended)
  • bootstrap.esm.js – ES Module version
icons(Bootstrap Icons package)

Contains the Bootstrap Icons library (installed separately).

  • font/ – Icon font files (.woff2, .ttf)
  • bootstrap-icons.css – CSS to use icon fonts
  • icons/ – Individual SVG icon files
  • bootstrap-icons.svg – SVG sprite sheet
